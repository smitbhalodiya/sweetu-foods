# Project Name: Sweetu Foods

Sweetu Foods is a responsive restaurant website designed to showcase healthy food options. It features a modern layout with a navigation bar, a showcase area, an about section, food categories, a detailed food menu, customer testimonials, and a contact form.

## Project Link

- [Live Demo](https://smitbhalodiya.github.io/sweetu-foods)

## Features

- **Responsive Design**: The website is fully responsive and works well on desktop, tablet, and mobile devices.
- **Smooth Scrolling**: Navigation links use smooth scrolling for a better user experience.
- **Interactive Menu**: A visually appealing food menu section.
- **Testimonials**: A section to display customer reviews and ratings.
- **Contact Form**: A form for users to get in touch.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling, including Flexbox for layout and media queries for responsiveness.
- **jQuery**: For smooth scrolling functionality.
- **Font Awesome**: For icons.
- **Google Fonts**: Uses 'Poppins' font family.

## Setup and Usage

1.  Clone the repository or download the source code.
2.  Open `index.html` in your web browser.

## File Structure

- `index.html`: The main HTML file containing the website structure.
- `style.css`: The CSS file for styling the website.
- `img/`: Directory containing images used in the website.
